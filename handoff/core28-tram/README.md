# core28 · 電車模型評估（3D）

**結論：** 用程序模型，唔用 CC0 下載。現成嘅 CC0 電車多數係歐洲單層款，唔似香港雙層窄身電車，而且多數有原廠塗裝要清走；自己砌形狀準啲，亦冇版權同商標風險。

## 原型 `modZe_tram_core28.js`
- 形狀：雙層窄身車廂，下層有腰板同窗帶，上層係連續窗，兩頭駕駛室、微拱車頂，車頂有集電桿，兩個轉向架共 8 隻車輪。
- 尺寸：長 12m、闊 2.4m、高約 4.7m（連集電桿），軌距 1.067m。全部係近似值，要用參考圖再校。
- 塗裝：有 3 款通用顏色（綠配米白、紅配米白、藍配米白）。車身只寫「港島叮叮」戲仿字，**冇真電車公司 logo 或全稱**。
- 廣告板：兩側腰線用法律表入面嘅戲仿店名，例如「金河電腦城（戲仿）」。兩頭有目的地牌。
- 效能：同材質嘅幾何已經合併。實測兩架電車連地面同路軌共 40 個 draw call、4,410 個三角形，即每架大約 18 個 draw call，Safari 都頂得順。
- 行駛：`NT.tramRunner(tram, pts, {speed, dwell})` 會沿住 polyline 行，去到 `stop:true` 嘅點會停站。

## 試法
開 `handoff/core28-tram/test.html`（同 `index.html` 共用 vendor three），預覽圖係 `tram-preview.png`。

## 合入 core28 建議
1. 由 `TRANSIT.tram` 6 個站（堅尼地城至北角）連成軌道 polyline，用 `hkGeo` 計座標。灣仔同東區先放 2–3 架行駛，其他路段唔生成。
2. 路軌用兩條幼 box 嵌入路面，架空電線用 1–2 條細 line 加電線桿，唔使逐條做。
3. 撞車：先當實心障礙物，車撞到就停；電車照軌道行，唔會閃避。
4. 搭車：沿用現有 `transitRideTram` 快速移動選單，下一版先做坐上層第三身。
5. 待確認：集電桿定集電弓、上層窗格數、車頭弧度，請人物或美術畀參考圖。
