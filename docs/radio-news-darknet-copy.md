## 2. 動態新聞池（接 `radioWantedNews`／`wantedCleared`）

用語：對外 **通緝級 N**；可用「差人／警察／司警／O記」分級（跟 de-gta 表）。**禁止**：真台名前綴、真警察編制全名堆砌、真歌曲名。

### 2.1 通緝升級（`raiseWanted` 且級別上升）

**hk**（抽 1）
1. `突發：警方通緝升級至「通緝級 {n}」，呼籲市民勿自行靠近。`
2. `交通台：有高速追逐目擊報告，駕駛人士請改道。`
3. `新聞：油尖旺／深水埗一帶加強截查——通緝級 {n}。`
4. `（級≥4）快訊：高層單位介入——街頭氣氛轉冷，請勿圍觀。`
5. `（級≥3）衝鋒隊加強巡邏；低通緝級市民照常出入。`

**mac**
1. `燈塔之聲：司警關注娛樂場一帶異常，現為通緝級 {n}。`
2. `新聞：口岸加強檢查，旅客請備齊證件。`
3. `（級≥4）快訊：跨境聯動戒備提升——硬闖大橋屬高危。`

**tw**
1. `島嶼新聞網：北／南部同步戒備，通緝級 {n}。`
2. `新聞快報：有持械案件通報，民眾勿圍觀。`
3. `夜市廣播（台語味）：警察追緊矣——通緝級 {n}，路邊少停。`
4. `軌道電台：城市警報升了一格。保持低調。`

`{n}` = 1–5；可選插入 `LM.wantedTier` 文案（若有）取代純數字。

| 做法 | 可否 | 說明 |
|---|---|---|
