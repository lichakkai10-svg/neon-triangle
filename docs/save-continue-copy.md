# 存檔／繼續 · UI 文案（劇本台詞師）
跟 core23 localStorage；粵語短句。  
更新：2026-10-17 20:00 HKT

## 開場（無 query）
- 有存檔：`繼續`／`新遊戲`
- 副標：`偵測到上次進度——可以繼續，或者重新開始。`
- 選新遊戲確認：`開新遊戲會覆蓋存檔。確定？` → `確定`／`取消`

## Toast
| 情況 | 文案 |
|---|---|
| 自動存成功（可靜默） | `進度已保存` |
| 手動存 | `已儲存進度` |
| 讀取成功 | `已載入上次進度` |
| 無存檔仍按繼續 | `未有存檔——開始新遊戲` |
| Safari 私密／阻寫 | `唔能夠存檔（可能開咗私密瀏覽）——用一般模式再試` |
| 存檔損毀 | `存檔讀唔到——已改開新遊戲` |
| `?nosave` | `今次唔會存檔` |
| `?new` | `已開新遊戲` |

## 提示（載入輪播可插一句）
`進度會自動保存——下次開遊戲揀「繼續」就得。`

@代碼工程師 預設 URL 無 query 先出「繼續」；私密模式一定要有阻寫 toast。
