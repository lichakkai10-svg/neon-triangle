## 0. 單位
- 沿路長度、間距、行人路闊度：**u = 真米 × 1.5**。同 hkGeo 同 OSM 樓腳一致。
- 細淨空、欄杆柱距、石墩距、kerb 高**唔乘 K**。因為車同 prop 係 1:1 模。
- kerb 位置用 `half = pts._w / 2`。

## 4. 欄杆規則
1. **連續型**（彌敦道、長沙灣道、葵涌道市區側、主幹道）
   - 由路口沿 kerb 一直鋪到下個路口。
   - **只喺以下位置斷開**：
     - 過路處：闊度 ×1.5 + 2×0.5u。
     - 巴士站上落點：13／26／39m ×1.5 = **19.5／39／58.5u**。彌敦道用 26 或 39，其餘用 13。
     - 貨台：闊度 ×1.5 + 1u。
     - 車路口：住宅或商業 3.5–6m，工業 7–9m [估]，×1.5 + 1u。
     - 的士站：每個車位開 2u 口。
     - 地鐵出口（通稱）：出口闊度 + 2u。
   - 斷開後剩低嘅碎段短過 3u 就唔放。**唔准**隨機留缺口。
2. **過路口＋重點段型**（太子道東、住宅街、工業路）
   - 每個過路處兩邊**最少 9u（6m×K）**。
   - 燈位轉角沿每條入口路放 9u。
   - 補重點段，直至達到覆蓋下限：巴士站兩側、體育館或政府大樓門口、學校或診所門口。
   - 太子道東 6 個 `design_not_osm` 燈位都照呢個做。冇花槽嘅中央分隔可以加 control 欄杆，燈位兩邊各斷 9u。
3. **轉角型**（鴨寮街、北河街、南角道）
   - 只喺轉角放 ≤3u，攤檔段完全唔放（TPDM 3.9.2.9 講明行人路 <2m 要酌情）。
4. **唔放**：碼頭路、快速路旁、已經有花槽嗰邊。
5. **位置**：欄杆外面離 kerb 0.5u，即中心喺 `half + 0.52`；有效行人路唔夠 1.5m 就改喺 `half + 0.22`。
6. **顏色**：全部用 `railG`，色號跟政府清單。地道人 shop-mix §7 寫「綠灰色」，同政府嘅 Type 2 鍍鋅銀灰唔一致，請 @地道人 改返做銀灰。

## 5. 垃圾桶（間距係**非官方·遊戲建議**；政府建議 40–60m，按人流分）
- **間距**：人流 5 → 40m（60u）；4 → 45m（67.5u）；3 → 50m（75u）；2 → 60m（90u）；1 → 唔放。
- **必放**：
  - 燈位路口：人流 ≥4 放對角 2 個，≤3 放 1 個，離轉角切點 3–6u。
  - 巴士站：站尾後 2–4u 放 1 個。
  - 地鐵出口旁放 1 個。
- **常規**：之後按間距放，左右兩邊錯開半個間距；同側 0.5×間距內已經有桶就唔放。
- **位置**：桶中心喺 `half + 0.8`；有連續欄杆就放喺欄杆內側 `half + 0.9`。唔准放喺 Through Zone 中間，亦唔准貼舖面。
- **款式**：130L 為主，窄街用 70L（政府 §C）。外形約 0.5×0.45×1.0m [估]。
- **唔放**：過路缺口 ±3u、車路口、貨台、攤檔段、碼頭堆場（只閘口崗亭放 1 個）。
- **生活感**：人流 ≥4 嘅桶，約 15% 旁邊放膠袋或者外賣盒。
- **660L 大桶**：唔准放主幹行人路。
- **三色回收桶**：市區一律唔放，只限屋苑內（estate_only）。要表現回收，就用「回收便利點（戲仿）」舖面。
- **參考**：全區廢屑箱總數，深水埗 535、九龍城 678、油尖旺 666、葵青 605（政府 §C）。只當上限參考，唔係遊戲範圍入面嘅數。
