# 臨時封閉／行人專用牌（戲仿）— 遮打道假日等

負責人：政府部門／大公司  
用途：星期日／公眾假期遮打道行人優先、其他臨時封路（**唔係**工地）  
對齊：`docs/core29-central-holiday-gathering-layout.md`、`docs/streetscape-central-fdw-sunday.md`  
更新：2026-10-24（HKT）  
**未推 Pages**

## 0. 硬規則

| 准 | 禁 |
|---|---|
| 通用封閉／改道／行人專用句 | **「前面修路」「工程進行中」**（工地句，另見 `sign_works`） |
| 中英兩行（中文上、英文下） | 真部門全稱做主標、真徽號、真熱線、真承建商 |
| 戲仿機關小字（可選）：`道路管理處（戲仿）` | 路政署／運輸署／警務處真名或徽章 |
| 水馬、雪糕筒、黃黑橫紋欄做實體封閉 | 假日封路扮成掘路／圍板工地 |

通用「前面修路」牌本身可照真牌句式（見房間拍板）；**假日行人化唔好用嗰句**。

## 1. Prop id

| id | 用途 | 何時刷 |
|---|---|---|
| `sign_temp_ped` | 臨時行人區／假日封閉主牌 | 遮打道假日 10:00–18:00；其他日程封路可重用 |
| `sign_temp_divert` | 請改道／車輛改行 | 封段兩端入口、改道箭嘴位 |
| `sign_temp_closed` | 此路段暫時封閉 | 短支路／出入口完全唔起車 |

工地繼續用現有 `sign_works`／`cone_temp`，**唔好同 `sign_temp_ped` 混用**.

## 2. 建議字面（可直接貼 mesh）

### 2.1 主牌 `sign_temp_ped`（遮打道假日）

```
臨時行人區
TEMPORARY PEDESTRIAN ZONE

星期日及公眾假期
SUNDAYS & PUBLIC HOLIDAYS
10:00 – 18:00

車輛請改道
VEHICLES FOLLOW DIVERSION
```

可選底行小字（戲仿，唔用真熱線）：`道路管理處（戲仿）`

### 2.2 改道牌 `sign_temp_divert`

```
請改道
PLEASE FOLLOW DIVERSION

→（箭嘴跟關卡改道路線）
```

短版（水馬頂／A 字牌）：

```
臨時封閉 · 請改道
ROAD CLOSED · DIVERT
```

### 2.3 完全封閉 `sign_temp_closed`

```
此路段暫時封閉
THIS SECTION TEMPORARILY CLOSED
```

### 2.4 行人提醒（聚集區內、可極疏）

```
請勿阻塞通道
PLEASE KEEP CLEAR
（戲仿）
```

同地道人 `streetscape-central-fdw-sunday.md` 臨時告示一致；**唔寫**真 NGO／領館／教會。

## 3. 外觀（遊戲建議 · 非官方尺寸）

| 項 | 建議 | 標記 |
|---|---|---|
| 底色 | 白底黑字；或紅框白底（禁令感） | [非官方·遊戲建議] |
| 主標 | 中文較大、英文較細；兩行對齊 | 跟街名牌習慣 |
| 板高 | 約 0.9–1.2 m（立桿或水馬夾） | [非官方·遊戲建議] |
| 擺位 | 封段**兩端**各至少 1；長段中間可加 1；箭嘴牌對住可駛出口 | — |
| 水馬 | 黃／白臨時水馬連成線；缺口只留行人／緊急 | 跟關卡 footprint |

未搵到「假日行人區牌」官方外框 mm 數；有官方出處再改標記。

## 4. 日程（遮打道）

| 時段 | 牌／水馬 |
|---|---|
| 日–六、同日 18:00 後 | **收起** `sign_temp_*` 同封路水馬；恢復可駛 |
| 日／公眾假期 10:00–18:00 | 刷 `sign_temp_ped`＋兩端 `sign_temp_divert`；按 layout 可選水馬 |
