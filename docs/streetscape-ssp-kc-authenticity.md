## A. 深水埗區 `sham_shui_po`

街格：**棋盤格**（南北：桂林街、北河街、基隆街… 東西：長沙灣道、福華街、鴨寮街、大南街、汝州街）——短 block、十字路口密，**冇直長路**；主幹長沙灣道／荔枝角道東西向。

| 重點 | 真實街貌 | 遊戲做法 | 唔好 |
|---|---|---|---|
| **鴨寮街** | 二手電子、電池、插頭、舊手機地攤＋鐵皮小檔；兩邊唐樓舖 | 行人為主窄街；路中兩排矮攤檔（帆布頂、紙皮箱、膠箱）；日間人多 | 霓虹招牌雨；整齊商場感 |
| **北河街** | 街市檔＋老字號豆品／糖水（戲仿）；北河街街市（政府街市大樓） | 濕地面＋菜檔／肉檔棚；街市大樓灰白矮座 | 用真「公和」等字號 |
| **黃金電腦商場** | 福華街／桂林街一帶商場入口，地庫＋地面電腦舖 | 外觀＋入口凹位，牌寫「黃金電腦（戲仿）」或「福華電腦商場（戲仿）」；可作可入室 | 真商場 logo |
| 桂林街／欽州街 | 唐樓騎樓、舊式茶餐廳、熟食檔 | 唐樓 6–9 層、冷氣窗機疏密混搭 | 高樓 CBD |
| 汝州街／基隆街 | 布料、鈕扣、花邊批發舖 | 舖口布卷、膠袋綑貨 | |
| 長沙灣道 | 時裝批發、雙線車路、巴士 | 主幹可駛；入區由油尖旺北（太子／界限街）接入 | 高速護欄 |
| 大南街 | 皮革舖＋新式咖啡店混合 | 少量暖色細舖 | |
| 公屋／舊樓 | 南山邨、石硤尾（北面山邊） | 遠景程序塊 | |

交通：深水埗站（荃灣綫）出口喺**北河街／桂林街一帶**；巴士小巴密；**冇電車**。

## B. 九龍城區 `kowloon_city`

街格：**舊九龍城低矮唐樓**（舊啟德航道限高歷史，樓偏矮 6–12 層），街短窄；接 **啟德**（東南）新發展區。

| 重點 | 真實街貌 | 遊戲做法 | 唔好 |
|---|---|---|---|
| **九龍寨城公園** | 原城寨遺址改中式園林（衙門、南門遺蹟、亭、池）；東正道／東頭村道一帶 | 園林圍牆＋門樓（程序）、內部石徑；靜區 | 重建成黑暗城寨大樓（寨城 1994 已拆） |
| **九龍城街市** | 衙前圍道「九龍城街市及政府綜合大樓」，樓上熟食中心 | 大型灰白多層市政大樓＋地面濕街市入口 | 真康文署徽 |
| **侯王廟** | 聯合道旁小古廟，傍山 | 小型嶺南廟頂（綠瓦）＋香爐；細、低調 | 放大成大佛級地標 |
| **泰菜街** | 南角道、城南道、衙前圍道、獅子石道——泰式餐廳、泰雜貨 | 夜間暖黃燈箱、泰文字戲仿；街窄雙邊泊車 | 曼谷式霓虹過量 |
| 獅子石道／福佬村道 | 潮州老店、甜品、雜貨 | 唐樓地舖密 | |
| 太子道西／東 | 主幹，接油尖旺北／旺角東；東接啟德 | 可駛主幹；彎、有燈位 | 一條直長路通晒 |
| 宋皇臺花園 | 馬頭涌道，宋王臺石刻 | 小公園＋石碑 | |
| 啟德接口 | 舊機場跑道新區、啟德體育園 | 入區位遠景／新式大樓；**唔好畫舊跑道仲有飛機升降** | |

交通：宋皇臺站／啟德站（屯馬綫）近邊緣；九龍城中心本身**冇鐵路站**，靠巴士／小巴——呢點要啱。

## C. 兩區共通

- 騎樓、招牌伸出街但**疏過旺角**；九龍城更矮更靜。
- 地面：瀝青車路＋舊階磚行人路；渠蓋、橙桶（§6 疏排）。
- 駕駛：短 block＋多燈位＋泊車擠逼——**冇直長路**（交 @gta團隊 驗）。
- 方言：街坊粵語；九龍城有泰語／潮州話零星點綴（音效／路人台詞輕手）。
