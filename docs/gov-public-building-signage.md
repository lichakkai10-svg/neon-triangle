# 公營建築入口牌／告示（戲仿 · 無真徽）

負責人：政府部門／大公司  
對齊：`docs/boss-p0-batch-and-public-buildings-2026-10-24.md`（massing 歸關卡／地道人）  
用途：門牌、入口指示、臨時告示字面；**唔做**真部門徽、真院徽、真校徽、真港鐵 M 標  
更新：2026-10-24（HKT）  
**未推 Pages**

## 0. 硬規則

| 准 | 禁 |
|---|---|
| 通稱＋戲仿地名（見下表） | 路政署／食環署／運輸署／康文署／醫管局／警務處**真徽** |
| 白底黑字或灰底白字門牌；中英兩行 | 真十字紅十字／紅新月做醫院主標（急症用「急症／A&E（戲仿）」字） |
| 旗杆位可有空白旗布或純色（無圖案） | 真區旗／真國徽貼門 |
| 閘機／圍欄外「訪客請登記（戲仿）」 | 真熱線、真院號、真校網編號 |

Massing／外牆物料跟老闆公營視覺說明；本檔只鎖**字同徽**.

## 1. 門牌句式（可直接貼）

| 類型 | 中文主標（例） | 英文 | 備註 |
|---|---|---|---|
| 政府辦公 | `市政大樓（戲仿）` | `Municipal Building (Parody)` | 可加 `訪客入口` |
| 醫院 | `廣華坊醫院（戲仿）`（已有外牆牌可重用） | `Kwong Wah Lane Hospital (Parody)` | 急症落客：`急症入口 A&E`；**唔用**紅十字主標 |
| 診所／健康院 | `社區健康中心（戲仿）` | `Community Health Centre (Parody)` | — |
| 學校 | `中環官立小學（戲仿）`／`區內中學（戲仿）` | `… Primary / Secondary School (Parody)` | 校名戲仿，唔抄真校 |
| 食環街市 | `某某街市（戲仿）` | `… Market (Parody)` | 已有：九龍城街市（戲仿）；熟食中心通稱 OK |
| 公屋屋邨牌 | `和諧邨（戲仿）`／`康和苑（戲仿）` | 英文邨名戲仿 | 色帶 massing 歸美術／關卡；牌唔印房署徽 |
| 文康／公園 | `公園`／具名公園（真地名可） | `Park` | **禁康文署徽**（寨城公園先例） |
| 巴士總站 | `巴士總站 BUS TERMINUS` | — | 路線號虛構 |
| 碼頭 | `渡輪碼頭 FERRY PIER` | — | 戲仿航線名 |
| 港鐵出入口亭 | `車站出口`＋字母（A/B/C） | `Exit A` | **禁真 M 標／真站名牌樣式照抄商標**；站名用遊戲已鎖戲仿名（葵芳等） |

```

AMBULANCE ACCESS  NO PARKING

```

```
校門關閉時段
GATE CLOSED HOURS
（戲仿）
```

醫院／學校外唔好堆真部門宣傳橫額。

## 3. 舊區 vs 新市鎮（牌密度）

| | 舊區 | 新市鎮 |
|---|---|---|
| 政府／街市牌 | 貼樓面、細、生鏽感可有 | podium 玻璃門上整潔燈箱 |
| 公屋 | 邨門石碑／金屬字 | podium 商場側邨牌＋車場箭嘴 |
| 醫院 | 舊翼石材字＋新翼燈箱可並存 | 單一玻璃幕牆門廊牌 |
