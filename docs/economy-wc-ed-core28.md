## 5. 防刷同玩法
- 同一 id 同一區 120 秒內只罰一次；有通緝時唔再疊罰款，改為加熱度 +0.1。
- 春秧街電車阻路係今次特色：響鐘後 3 秒內讓開就冇事；罰則用 `hk_tram_obstruct` $50（法律核，唔再用 `hk_obstruction` $150）。開車停軌另用 `hk_veh_obstruct_road` $8。
- 東灣城中心保安區通緝 ≥1 會拒絕入場，唔另設罰款。
- 唔設收贓點，兩區都係住宅或者商業區。
