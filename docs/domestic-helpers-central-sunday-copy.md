# 外傭假日中環 · 台詞（core27f+）

老闆拍板：做；**普通市民造型**；**唔做口音笑位**（唔寫假腔拼音搞笑）。
地點感：中環／遮打道／天星附近休憩帶（戲仿），星期日日頭。

## 原則
- Tagalog／印尼語用**短、常見、尊重**嘅招呼／聚餐句；粵語用自然招呼，唔模仿外口音。
- 禁真領事館、真 NGO、真僱主中介品牌名。
- 告示用戲仿機構通稱。

## 粵語（本地路人／店員）

2. 「唔該借借，我行過。」
3. 「遮打道行落去多人啲。」
4. 「有野餐墊㗎，坐低先。」

## Tagalog（短句＋括號意思；字幕可出中／英）
1. 「Kumusta!」——你好
2. 「Salamat.」——多謝
3. 「Tara, kain tayo.」——走，一齊食
4. 「Linggo ngayon, libre.」——今日星期日，休息
5. 「Saan tayo uupo?」——我哋坐邊？
6. 「Ingat pauwi.」——返去小心
