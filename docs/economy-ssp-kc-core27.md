## 0. 規則
- 遊戲$ ≈ 港幣 ÷40，四捨五入，**最低 $1**（小食／街市再平都 $1，等深水埗「平」有體感）。
- 「現實體感」欄係設計估算（街坊價位級數），**唔係官方統計**；Safari 玩感先準。
- 罰款金額全部讀 `fines-official.json` 嘅 `game_amount`，呢份只定**觸發位**，唔新增罰則。
- 店名一律戲仿，交 @法律 抽查。

## 4. 頻率／防刷
- 同一 id 同一區 120 秒內只罰一次；通緝 ≥1 時改為加通緝熱度 +0.1，唔再疊罰款。
- 深水埗攤檔帶阻街只對玩家，NPC 攤主唔罰（避免「執法者欺負小販」炎上）。
- 九龍城食街違泊只喺 19:00–02:00 遊戲時加倍頻率，日間正常。
