## 類型池（輪出用）

| 類型 | massing 要點 | 優先出現帶 |
|---|---|---|
| **唐樓** | 騎樓／有蓋廊；柱距同 P0；地舖淨高 2.8–3.5 m；上層 2.7–3.2 m | 高密度舊區 |
| **公屋** | 和諧／康和十字或 Y；色帶＋窗花；層高 2.7–2.9 m；常連 podium 商場／車場 | 葵青邊、新市鎮、黃大仙／觀塘 |
| **podium＋塔** | 低座 3–6 層商場／泊車＋塔樓；地面入口少 | 沙田／荃灣／屯門／將軍澳 |
| **寫字樓** | 玻璃／石材幕牆；大堂＋閘 | 中環、尖沙咀、灣仔、荃灣市中心 |
| **工廈** | 大方塊、貨櫃車灣、少行人 | `kwai_tsing` 工業、火炭邊 |
| **公營** | 政府樓／醫院（避真十字）／學校色帶／街市簷篷／文康盒 | 全区；告示跟政府 doc |
| **交通** | 戲仿港鐵亭、巴總有蓋坑、碼頭欄杆；葵涌起重機貨櫃 | 車站／碼頭／貨櫃區 |

## 18 區用法
- 跟 `hk18-district-density-mix.md` 密度帶抽類型比例，**唔好**全區單一模。
- 每區「代表性建築」細名單：老闆話等指定區再開再補；未開區只留 hk18 skeleton。
- **葵涌 ≠ 葵芳**；南緣擦葵青用「葵青區 · 往葵芳（戲仿）」牌。

## 唐樓柱（P0 鎖）
- 柱心→舖門檻：1.0–1.8 m（遊戲 u ×1.5 → 1.5–2.7）
- 柱心→路壆：1.2–2.0 m（u 1.8–3.0）
- 多數地界內、騎樓跨行人路；唔侵車路
