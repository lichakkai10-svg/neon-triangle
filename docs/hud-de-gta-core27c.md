# core27c HUD 去 GTA 清單（宣傳片用）
負責：gta團隊 · 跟 `de-gta-rename-table.md` · 唔郁 Pages

## 禁（太似 GTA）
- 左下角圓形雷達＋右上角錢／星嘅組合佈局
- 五粒白星通緝、藍紅警燈閃邊
- Pricedown 類粗斜體字、綠色 $ 數字
- 武器輪盤圓形分格、任務完成大字橫幅（MISSION PASSED / WASTED 款）
- 黑底白字 loading 藝術插畫

## 用（自家設計）
- 地圖：方形或者圓角，放右下角，跟真街名，唔使雷達掃描感
- 錢：`HK$ 1,234`（台灣用 `NT$`），細字、白色或者米色，唔用綠色
- 通緝級：用文字加 1–5 格橫條，例如「通緝級 ▮▮▯▯▯」，唔用星
- 事件字：搞掂／搞砸／掛咗／拉咗，用港式招牌字或者手寫字，細細一條，唔用全屏橫幅
- 罰款提示：「闖紅燈 −HK$900」細 toast，跟 `fines-official.json`

## 拍片時
- 只用實機畫面，HUD 可以淡出；行街鏡頭建議隱藏 HUD
- 唔好砌 GTA 式三分鏡 loading 圖或者斜角人物海報
