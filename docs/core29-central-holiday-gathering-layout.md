## 規則
- **時段：**只日／公眾假期 10:00–18:00 刷聚集 props／高人流；平日同 18:00 後收返。
- **碰撞：**紙皮／墊席＝無碰撞或軟碰撞；緊急通道同碼頭出入口唔擋。
- **欄杆：**車路邊仍跟 Type 2；聚集帶內可疏，斷口跟過路／站口。
- **命名：**真街名／公園名 OK；禁真 NGO／領館／教會／雇工中心名同橫額。
- **天橋／中環扶梯：**仍留後一版；今版聚集唔依賴天橋。
