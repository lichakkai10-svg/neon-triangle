# 灣仔＋東區 駕駛節奏檢查（core28）
負責：gta團隊 · id 用長碼 `wan_chai`／`eastern` · 唔郁 Pages

## 最大風險：直長路
- **告士打道、東區走廊**：真路好直好快，最似 GTA 嘅高速路。core28 唔開東區走廊做可駛；告士打道如果要開，要用燈位、匯合線同天橋落腳位，切到每段 ≤400。
- **軒尼詩道、英皇道**：兩條都長直，靠電車站、電車路口、斑馬線同巴士站切斷，唔准一路連續綠燈。
- 參考 core27 嘅標準：最長直路大概 400，超過就加實體燈號、安全島或者變線（`design_not_osm` 要寫明），唔可以用隱形點。

## 灣仔（`wan_chai`）
- 主幹：軒尼詩道（東西走向，兩邊有電車）、謝斐道、港灣道，中速，路口密。
- 慢區：莊士敦道（有電車路軌，樓貼住街）、皇后大道東、太原街同交加街一帶嘅街市窄街（擺檔，近乎行人速度）。
- 有坡有彎：堅尼地道上山，彎多，唔准拉直；禮頓道接銅鑼灣同跑馬地要有轉向位。

## 東區（`eastern`）
- 主幹：英皇道（北角到筲箕灣，有電車），每個電車站或者大路口就斷一段。
- 渣華道、電氣道：同英皇道平行，短 block，街市一帶慢駛。
- 鰂魚涌街、太古城道：有彎、有迴旋處，唔好拉直接海旁。

## 驗收
- [ ] 冇一條「一油衝到尾」嘅直路，告士打道／東區走廊照上面規則處理
- [ ] 電車路段唔可以快過主幹，電車站要迫車慢落嚟
- [ ] 入區位（灣仔接中西區／銅鑼灣、東區接灣仔）要有轉向位
